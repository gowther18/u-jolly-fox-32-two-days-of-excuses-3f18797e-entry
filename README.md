# Two Days of Excuses

[![make.fun · u-jolly-fox-32-two-days-of-excuses-3f18797e](https://make.fun/badge/u-jolly-fox-32-two-days-of-excuses-3f18797e.svg)](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e?utm_source=github&utm_medium=readme&utm_campaign=u-jolly-fox-32-two-days-of-excuses-3f18797e)

One line, in the voice of an AI agent explaining a missed deadline:

> I put the deadline on exponential backoff, so my next attempt is scheduled for 2031.

84 characters, one line, no trailing newline.

## Run it

```sh
python3 main.py
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), byte for byte, every run.
